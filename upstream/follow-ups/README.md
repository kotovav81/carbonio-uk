# Empty-English follow-up

`empty-english-keys.yaml` is a proposal package for a future clarification
with Zextras. It is deliberately separate from the current Ukrainian catalogs:
no item here is installed or merged into `translations/uk/`.

The proposals were derived from:

- fallback English strings in the current component source where available;
- established terminology in the current Ukrainian catalogs;
- non-empty values in peer upstream locales;
- placeholder and markup preservation rules.

Before submitting these values upstream, ask maintainers to confirm whether the
keys belong in the English source catalog. If the English catalog remains empty
by design, the application fallback may be the canonical source and the
translation repository should document that policy.

This follow-up is intentionally not a claim of 100% coverage.
